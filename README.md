## 🎯 About

Ova is a state-of-the-art web application that combines the power of Next.js with real-time WebSocket communication. Built on a robust TypeScript foundation, it implements industry best practices and provides a scalable architecture for modern web applications.

### ✨ Key Features

- 🚀 **Next.js 14** - Latest features and optimizations
- 🔒 **Type-Safe** - Full TypeScript support
- 📡 **Real-time** - WebSocket communication
- 🎨 **Modern UI** - Custom Google Font (Inter)
- 🗃️ **Prisma ORM** - Robust database management
- 📱 **Responsive** - Mobile-first design
- 🔐 **Secure** - Implements security best practices
- ⚡ **Fast** - Optimized performance
- 🌐 **SEO Ready** - Built-in SEO optimization

## 🚀 Getting Started

### Prerequisites

Before you begin, ensure you have the following installed:
- Node.js (v18 or higher)
- Package manager (npm, yarn, pnpm, or bun)
- Git

### Quick Start

1. **Clone the repository**
   ```bash
   git clone https://github.com/ankitmalik84/ova.git
   cd ova
   ```

2. **Install dependencies**
   ```bash
   npm install
   # or
   yarn install
   # or
   pnpm install
   # or
   bun install
   ```

3. **Start development server**
   ```bash
   npm run dev
   # or
   yarn dev
   # or
   pnpm dev
   # or
   bun dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser
