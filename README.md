# 🎯 Ova - Next.js Web Application

## 📖 About

Ova is a modern web application built with Next.js, featuring real-time WebSocket communication and a robust TypeScript foundation. The project implements best practices in web development and provides a scalable architecture for building interactive web applications.

## ⚡ Features

- 🚀 Built with Next.js 14
- 📊 TypeScript for type safety
- 🔄 Real-time WebSocket communication
- 🎨 Modern UI with custom Google Font (Inter)
- 🗃 Prisma for database management
- 📱 Responsive design
- 🔒 Security best practices

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or higher)
- npm, yarn, pnpm, or bun

### Installation

1. Clone the repository:
```bash
git clone https://github.com/ankitmalik84/ova.git
cd ova
```

2. Install dependencies:
```bash
npm install
# or
yarn install
# or
pnpm install
# or
bun install
```

3. Start the development server:
```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

4. Open [http://localhost:3000](http://localhost:3000) in your browser to see the application.

## 🗂 Project Structure

```
ova/
├── app/                  # Next.js app directory
├── prisma/              # Prisma database configuration
├── public/              # Static assets
├── components.json      # UI components configuration
├── next.config.mjs      # Next.js configuration
├── tailwind.config.ts   # Tailwind CSS configuration
└── tsconfig.json        # TypeScript configuration
```

## 💻 Development

- The application uses hot reloading - modify `app/page.tsx` and see changes instantly
- Built with modern React features and hooks
- Implements WebSocket for real-time communication
- Uses Tailwind CSS for styling
